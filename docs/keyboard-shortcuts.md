# Keyboard shortcuts (Windows)

Every command is also in the menu bar (press Alt), and F1 shows this list inside Reader.

## Books

| Command | Shortcut |
|---|---|
| My books | Ctrl+B |
| Open book | Ctrl+O |
| Online libraries | Ctrl+L |
| Close book (keeps your place) | Ctrl+W |

## Reading modes and speed

| Command | Shortcut |
|---|---|
| Text only | Ctrl+1 |
| Audio only | Ctrl+2 |
| Text and audio | Ctrl+3 |
| Faster | Ctrl+] |
| Slower | Ctrl+[ |

## Playback and navigation

| Command | Shortcut |
|---|---|
| Play or pause | Ctrl+Space |
| Next phrase | Alt+Right |
| Previous phrase | Alt+Left |
| Next heading | Alt+Down |
| Previous heading | Alt+Up |

In the book's text box in screen reader mode, Alt+Down and Alt+Up are left to your screen reader (for example the next and previous sentence commands of NVDA's sentenceNav add-on). Use H and Shift+H there to move by heading.

| Next page | Alt+Page Down |
| Previous page | Alt+Page Up |
| Next section (same level of the contents, skipping sub-sections) | Ctrl+Page Down |
| Previous section | Ctrl+Page Up |
| Go to page | Ctrl+G |
| Heading depth for navigation | Settings, or Navigate menu |

## Moving around the window

| Command | Shortcut |
|---|---|
| Table of contents | Ctrl+T |
| Book text, at your place | Ctrl+E |
| Where am I? | Ctrl+I |
| Settings | Ctrl+Comma |
| Reading commands (help) | F1 |
| Zoom in, zoom out, reset zoom | Ctrl+Plus, Ctrl+Minus, Ctrl+0 |
| Screen reader mode on or off | Ctrl+Shift+R |

## In the table of contents

After Ctrl+T, or Tab into the contents:

| Moves to | Key |
|---|---|
| Next / previous entry | Down / Up |
| Open a part, or go to its first entry | Right |
| Close a part, or go to the part it is in | Left |
| First / last entry | Home / End |
| Next entry starting with a letter | That letter |
| Go to the entry in the book | Enter |

## In screen reader mode

These keys work in the book's text box. Shift with the key goes backwards.

| Moves to | Key |
|---|---|
| Next heading | H |
| Next heading at a level | 1 to 6 |
| Next printed page | P |
| Next link | K (Enter or Space follows it) |
| Next table | T (Enter opens it as a real table) |
| Next list / list item | L / I |
| Next image / figure / separator | G / F / S |
| Next / previous section | ] / [ |
| Next / previous sentence (reads it) | . (full stop) / Shift+. |
| How far through the book | = |
