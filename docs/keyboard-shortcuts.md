# Keyboard shortcuts (Windows)

Every command is also in the menu bar (press Alt), and F1 shows this list inside Reader.

## Books

| Command | Shortcut |
|---|---|
| My books | Ctrl+B |
| Open book | Ctrl+O |
| Online libraries | Ctrl+L |

## Reading modes and speed

| Command | Shortcut |
|---|---|
| Text only | Ctrl+1 |
| Audio only | Ctrl+2 |
| Text and audio | Ctrl+3 |
| Faster | Ctrl+] |
| Slower | Ctrl+[ |

## Playback and navigation

| Command | Shortcut |
|---|---|
| Play or pause | Ctrl+Space |
| Next phrase | Alt+Right |
| Previous phrase | Alt+Left |
| Next heading | Alt+Down |
| Previous heading | Alt+Up |
| Next page | Alt+Page Down |
| Previous page | Alt+Page Up |
| Go to page | Ctrl+G |
| Heading level for navigation | Playback menu |

## Moving around the window

| Command | Shortcut |
|---|---|
| Table of contents | Ctrl+T |
| Book text, at your place | Ctrl+E |
| Where am I? | Ctrl+I |
| Reading commands (help) | F1 |
| Zoom in, zoom out, reset zoom | Ctrl+Plus, Ctrl+Minus, Ctrl+0 |
| Screen reader mode on or off | Ctrl+Shift+R |

## In the table of contents

After Ctrl+T, or Tab into the contents:

| Moves to | Key |
|---|---|
| Next / previous entry | Down / Up |
| Open a part, or go to its first entry | Right |
| Close a part, or go to the part it is in | Left |
| First / last entry | Home / End |
| Next entry starting with a letter | That letter |
| Go to the entry in the book | Enter |

## In screen reader mode

The book stays in your screen reader's browse mode, so use its own keys: for example H and 1 to 6 for headings, T for tables, L for lists, K for links, and say all.
