# Reader 0.10.2 (Sugamya downloads, headings with screen readers, download progress)

Released 22 November 2026 for Android phones and Windows PCs.

This version fixes the two problems reported on 0.10.0: **Sugamya Pustakalaya EPUB books that wouldn't download or open** (issue 6), and **heading keys with Narrator and NVDA** (issue 7). It also shows a **progress bar while a book downloads**. **Please try them and tell us what works and what doesn't.**

## Get the app

Both files are in the Saksham OneDrive folder **Reader tester builds / 0.10.2**, and in the DAISY folder **Reader experimental app / 0.10.2**.

| Device | File | Needs |
|---|---|---|
| Android phone | `Reader-0.10.2.apk` (56 MB, build 23) | Android 7 or later |
| Windows PC | `Reader-Setup-0.10.2.exe` (116 MB) | Windows 10 or 11, 64-bit |

Both install over 0.10.0 or any earlier tester build and keep your books, saved places, bookmarks and Sugamya sign-in. `SHA256.txt` in the same folder lets you check the files arrived intact.

To see which version you have: on Windows, **Help → About Reader**; on Android, the **Help** screen.

## Fixed: Sugamya Pustakalaya downloads (issue 6)

- **EPUB books download and open.** The library sends an EPUB inside a .zip file; Reader now opens the book inside. DAISY audio books, which come as a folder in a .zip, open too.
- **EPUB Text Only and Structured EPUB download straight away.** The library makes these in a few seconds, so after **Ask for this book** Reader waits for the link and downloads the book, as if it were a direct download.
- **My download requests says where each request is:**
  - **Ready to download.**
  - **Being prepared**, with the library's own status (for example "Queued"). DAISY audio books can take hours; one took about 17 hours.
  - **Link expired** for a format the library prepares later, once the link is more than 7 days old. Ask for it again.
  - For EPUB Text Only and Structured EPUB, an expired link is **asked for again by itself** and the book downloads.
- **A different book?** If the book that arrives has a different title from the one you asked for, Reader says so when it opens it.

**Please check:** ask for an EPUB Text Only book and a DAISY audio book. Does each one end up in My books and open?

## New: download progress

While a book downloads, from Sugamya Pustakalaya or another online library, a **progress bar** shows how far it has got, for example "40 percent, 12 MB of 30 MB". Screen readers can read the bar, and Reader says the progress every 10 percent (or every 10 MB when the library doesn't give the size). This matters most for audio books, which can be over 150 MB.

**Please check:** download a DAISY audio book. Do you hear the progress, and is it too often or not often enough?

## Fixed: headings with screen readers on Windows (issue 7)

In screen reader mode, H and Shift+H (and 1 to 6) move between headings.

- **NVDA** now says "Heading level 2, …" and the heading after each press. Before, it said only "h".
- **Narrator** now reads the heading Reader moved to, and its own place moves there, so Narrator's **next sentence** (Narrator + Ctrl + Full stop) and **next paragraph** (Narrator + Ctrl + L) start from the heading. Before, Narrator read some other line and its sentence and paragraph commands started from the old place.
- **Heading lines start with their level**, for example "Heading level 2: Two. Society as Objective Reality", so any screen reader says the level whenever it reads a heading line, also when you arrow onto it.

**Please check:** with Narrator, press H, then Narrator + Ctrl + Full stop. Does it read the sentence after the heading? With NVDA, does H say the level and the heading every time?

## Known limits

- **Narrator** still doesn't hear Reader's other messages while you're in the book text (for example "No next heading"). With NVDA they are spoken.
- **Narrator and other jumps:** jumps that land in the middle of a line (some Go back and bookmark positions) still move the cursor the old way, so Narrator may read the wrong line after them. Headings, which always start a line, are fixed.
- **Sugamya Pustakalaya:** one book (24008) is still refused by the library as an "offline request", and the website sometimes lists a request the app doesn't get. We have asked the library about both. Searching by language is not available yet.
- Reading aloud stops when the phone screen locks or you leave the app (Android).
- Display settings (font, spacing, colours) are not here yet; they are next.
