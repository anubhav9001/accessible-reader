# Reader 0.8.0 (Settings, sections and a smoother screen reader mode)

Released 7 November 2026 for Android phones and Windows PCs.

## Get the app

Both files are in the Saksham OneDrive folder **Reader tester builds / 0.8.0**.

| Device | File | Needs |
|---|---|---|
| Android phone | `Reader-0.8.0.apk` (55 MB, build 19) | Android 7 or later |
| Windows PC | `Reader-Setup-0.8.0.exe` (116 MB) | Windows 10 or 11, 64-bit |

Both install over any earlier tester build and keep your books and saved places. `SHA256.txt` in the same folder lets you check the files arrived intact.

To see which version you have: on Windows, **Help → About Reader**; on Android, the **Help** screen.

## On both

- **Settings**: reading speed, voice, heading depth (which headings next and previous heading stop at), how much of the contents is shown, and screen reader mode, all in one place. Windows: **File → Settings** or **Ctrl+,**. Android: **Settings** in the reader's More reading options menu, or the Settings button in My books.
- **Next section / Previous section**: move to the next or previous entry of the table of contents. Windows: **Ctrl+Page Down** and **Ctrl+Page Up**. Android: in More reading options.
- **Close book**: goes back to My books and keeps your place. Windows: **Ctrl+W** or **File → Close book**. Android: in More reading options.

## On Windows

### Screen reader mode

- No more freezing with NVDA on long books, and no pause at the end of the visible text: the text box now holds the part of the book around the cursor and moves on with you.
- Tables are readable: each row stays on one line, each cell says its column heading ("Date: 260 B.C. | Name: Battle of Mylae"), and the table is announced before and after. Press **Enter** on a table to open it as a real table, which you can read with your screen reader's table commands; Escape returns to the text.
- Moving by heading, table, link or another element now says what you reached, and says so when there is none ("No next table").

### Easier to use

- **The menu bar works like a Windows menu.** Press **Alt** or **F10** to reach it, or Alt with a menu's underlined letter (**Alt+F** for File). The arrow keys move; Tab stays in the menu; **Escape** goes back one step at a time (submenu, menu, menu bar, then back to where you were).
- **The toolbar is one Tab stop.** Use Left and Right to move between its buttons, Home and End for the first and last.
- **Icon toolbar.** The buttons show icons, with their names as tooltips; screen readers read the names. To show the names on the buttons too, turn on **Show text on toolbar buttons** in Settings.
- The Screen reader mode checkbox now sits in the Reading mode group, aligned with the other choices.
- **Help → Report a problem** opens the page for reporting a problem; **Help → About Reader** shows the version.

## On Android

- Settings, Next section, Previous section and Close book, as described above.
- The contents list follows the contents depth chosen in Settings.
- Screen reader mode: TalkBack reads each paragraph as one piece. It no longer reads a paragraph and then stops on its words one by one, and no longer says "new line" at the book's line breaks.

## Known limits

- Reading stops when the phone screen locks or you leave the app (Android).
- Sugamya Pustakalaya downloads in the app are still coming; download on the website and add the book with Add book.
