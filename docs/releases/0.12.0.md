# Reader 0.12.0 (eBraille books, display settings, headings from the contents)

Released 24 November 2026 for Android phones and Windows PCs.

This version **opens eBraille books**, DAISY's new braille e-book format, as readable print text or as the braille itself. It adds **display settings** for how the book's text looks, lets you **enlarge pictures**, and fixes problems you reported on 0.11.0: **H and Shift+H finding no headings** in some books (for example Social Background of Indian Nationalism), and a Sugamya search with an apostrophe that failed. **Please try them and tell us what works and what doesn't.**

## Get the app

Both files are in the Saksham OneDrive folder **Reader tester builds / 0.12.0**, and in the DAISY folder **Reader experimental app / 0.12.0**.

| Device | File | Needs |
|---|---|---|
| Android phone | `Reader-0.12.0.apk` (57 MB, build 26) | Android 7 or later |
| Windows PC | `Reader-Setup-0.12.0.exe` (117 MB) | Windows 10 or 11, 64-bit |

Both install over 0.11.0 or any earlier tester build and keep your books, saved places, bookmarks and Sugamya sign-in. On Windows, close Reader before installing. `SHA256.txt` in the same folder lets you check the files arrived intact.

## New: eBraille books

eBraille is DAISY's new format for braille books (eBraille 1.0, 2025), with the `.ebrl` file extension.

- **Opening one:** on Windows, **File, Open book** (or open a `.ebrl` file from File Explorer); on Android, **Add book**.
- **It opens as print text.** Reader translates the braille back to print with liblouis, the standard open-source braille translator, using the book's braille code: UEB, US English braille, or Bharati braille for Hindi, Marathi, Tamil and other Indian languages. The book then reads like any other: on screen, aloud with the device voice, and with your screen reader's speech.
- **To see the braille itself**, for a braille display: on Windows, **View, eBraille: switch braille or print text** (Ctrl+Shift+T); on Android, **More reading options, Show braille**. Switch back the same way; Reader remembers the choice. Shown as braille, the book can't be read aloud: Play says why.
- **Book information** names the format and shows the book's braille details (braille code, cell type, and so on).

**Please check:** if you have an eBraille book, does the print text read correctly? Shown as braille, does your braille display show the cells as they are?

## New: Display settings

**Settings, Display** changes how the book's text looks, on both apps:

- typeface (the book's own, sans serif, serif, Verdana or monospace), text size (75 to 300 percent) and bold;
- line spacing, space between words and space between letters;
- line length and margins;
- justified text (off by default, so lines don't spread out unevenly);
- text and background colours: six pairs, such as yellow on black or sepia, or your own;
- hiding printed page numbers in the text.

Changes show at once and are remembered; **Reset display settings** goes back to the start. Screen reader mode on Windows keeps its own look for now.

**Please check:** does the text look the way you choose? Is anything hard to find or use with your screen reader?

## New: enlarge a picture

Click a picture in the book (Windows) or tap it (Android) to open it on its own, as large as fits, with its description. Make it larger or smaller with **Ctrl+=** and **Ctrl+-** on Windows, or by pinching and with Larger and Smaller on Android.

## Fixed

- **H and Shift+H found no headings in some books.** Some books style their headings as ordinary paragraphs, so NVDA's H and Reader's Next heading said "No next heading" (for example Social Background of Indian Nationalism). Reader now takes the headings from the book's table of contents when the book hasn't marked them, in Text mode, screen reader mode and on Android.
- **A Sugamya search with an apostrophe failed** ("NSB's Banking Basics" said "That is not a Sugamya Pustakalaya request"). Windows.
- **The reading page could slide sideways** on Android after turning the phone, cutting off the start of each line.

**Please check:** in Social Background of Indian Nationalism, do H and Shift+H move from heading to heading?

## Known limits

- **eBraille:** tactile graphics in PDF are not shown yet. The translation is as good as liblouis's table for the book's braille code; tell us about any word that comes out wrong.
- **Narrator** still doesn't hear Reader's other messages while you're in the book text in screen reader mode (for example "No next heading"). With NVDA they are spoken.
- **Sugamya Pustakalaya:** searching by language is not available; one book (24008) is still refused by the library.
- Reading aloud stops when the phone screen locks or you leave the app (Android).
