# Reader documentation

Guides for people using and testing Reader, Saksham's accessible reading app for DAISY and EPUB books. "Reader" is a working name.

## For readers and testers

- [Getting started on Android](android-guide.md): install the app, add books, read and listen.
- [Getting started on Windows](windows-guide.md): install the app, add books, read and listen.
- [Keyboard shortcuts (Windows)](keyboard-shortcuts.md)
- [Frequently asked questions](faq.md)
- [Testing guide](testing-guide.md): what to try and how to report what you find.

## Releases

- [All releases](releases/README.md)
- Latest: [0.4.0, screen reader mode](releases/0.4.0.md) (4 November 2026)

## Report a problem or suggest an idea

- **[Report a problem](https://github.com/anubhav9001/accessible-reader/issues/new?template=tester-feedback.yml)**: something didn't work, was confusing, or could be better.
- **[Suggest an idea](https://github.com/anubhav9001/accessible-reader/issues/new?template=feature-idea.yml)**: something Reader should do that it doesn't yet.

You need a free GitHub account to report. See the [testing guide](testing-guide.md#reporting-what-you-find) for what to include.
